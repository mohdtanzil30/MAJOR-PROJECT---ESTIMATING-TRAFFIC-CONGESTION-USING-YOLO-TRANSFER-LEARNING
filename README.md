# MAJOR-PROJECT-ESTIMATING-TRAFFIC-CONGESTION-USING-YOLO-TRANSFER-LEARNING

This project implements a real-time traffic congestion estimation system using YOLOv8 object detection and transfer learning. It detects and counts vehicles in live video streams to dynamically classify congestion levels as Low, Medium, or High. The solution is built using Python, OpenCV, and the Ultralytics YOLOv8 model.

🚦 Features

- Real-time vehicle detection using YOLOv8
- Dynamic traffic congestion level classification
- Works in varying lighting and weather conditions
- Transfer learning for reduced training time and improved accuracy
- Dashboard output for congestion visualization
- Scalable for urban traffic monitoring applications

🛠️ Technologies Used

- Python
- OpenCV
- Ultralytics YOLOv8
- Google Colab (for model training)
- NumPy, Matplotlib
- Torch (PyTorch framework)

📊 Results
Achieved >90% vehicle detection accuracy

Real-time frame processing (20–25 FPS on GPU)

40% reduction in training time using transfer learning

Visual congestion level output per frame
